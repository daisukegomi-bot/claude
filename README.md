# 1年以上ぶり新高値（終値ベース）スクリーナー

[Yahoo!ファイナンス](https://finance.yahoo.co.jp/stocks) をソースに、**終値ベースで1年以上ぶりに新高値を更新した銘柄**をリストアップします。

## 判定方法

1. 日本株ランキング「年初来高値更新」（`/stocks/ranking/yearToDateHigh`、全市場・全ページ）から候補を取得
2. 各候補の時系列（`/quote/XXXX.T/history`）を新しい順に遡り、
   **最新終値以上の終値を付けた直近の日**を探す（株式分割を考慮した**調整後終値**で比較）
3. その日が365日以上前、または遡れた範囲（既定最大5年）に存在しなければ該当
   - 上場1年未満で判定期間に満たない銘柄は除外

## 使い方

```bash
pip install -r requirements.txt
python new_highs.py                    # 大引け後に実行
python new_highs.py --codes 7203 6758  # 指定銘柄だけ判定
```

結果は `results/YYYY-MM-DD.md` と `.csv` に保存されます（何年ぶりか・前回高値日つき）。

GitHub Actions（`.github/workflows/new-highs.yml`）で平日 16:45 JST に自動実行し、結果をコミットします。
手動実行は Actions タブの *Run workflow* から。

## 注意

- 候補は年初来高値（ザラ場高値ベース）ランキングから取るため、「終値は1年来高値だが
  ザラ場では年初来高値を更新していない」稀なケースは拾えません。
- 1〜2月は「年初来」の期間が短いので候補数が増え、取得に時間がかかります。
- リクエスト間隔（既定1秒）を短くしすぎないでください。
