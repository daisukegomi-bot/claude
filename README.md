# 株探 1年以上ぶり新高値（終値ベース）スクリーナー

[株探](https://kabutan.jp/) をソースに、**終値ベースで1年以上ぶりに新高値を更新した銘柄**をリストアップします。

## 判定方法

1. 株探「本日、年初来高値を更新した銘柄」（`/warning/?mode=3_1`、全ページ）から候補を取得
2. 各候補の日足時系列（`/stock/kabuka?code=XXXX&ashi=day`）を新しい順に遡り、
   **最新終値以上の終値を付けた直近の日**を探す
3. その日が365日以上前、または遡れた範囲（既定最大5年）に存在しなければ該当
   - 上場1年未満で判定期間に満たない銘柄は除外

## 使い方

```bash
pip install -r requirements.txt
python kabutan_new_highs.py                 # 大引け後に実行
python kabutan_new_highs.py --codes 7203 6758   # 指定銘柄だけ判定
```

結果は `results/YYYY-MM-DD.md` と `.csv` に保存されます（何年ぶりか・前回高値日つき）。

GitHub Actions（`.github/workflows/new-highs.yml`）で平日 16:45 JST に自動実行し、結果をコミットします。
手動実行は Actions タブの *Run workflow* から。

## 注意

- 候補は株探の年初来高値（ザラ場高値ベース）一覧から取るため、「終値は1年来高値だが
  ザラ場では年初来高値を更新していない」稀なケースは拾えません。
- 1〜2月は「年初来」の期間が短いので候補数が増え、取得に時間がかかります。
- 株探の利用規約を守り、リクエスト間隔（既定1秒）を短くしすぎないでください。
